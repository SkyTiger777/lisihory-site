# Маєток «Ліс і Гори» — сайт

Статичний багатосторінковий сайт маєтку в Поляниці (Буковель, Івано-Франківська область):
чотири дерев'яні оселі, басейн із підігрівом, лазня, смерековий ліс. Українською мовою,
з локальним SEO, мікророзміткою та адаптивом під мобільні.

- Живий прототип: `index.html` у корені проєкту (відкривається навіть через `file://`).
- **Зараз сайт зібраний під прев’ю-адресу `https://skytiger777.github.io/lisihory-site/`.** Перед запуском на власному домені замініть `BASE_URL` (див. нижче) і перезберіть сайт.
- **Живий прев’ю:** https://skytiger777.github.io/lisihory-site/
- Форма бронювання статична: вона не надсилає дані на сервер, а формує текст заявки та відкриває Viber або пошту.

---

## 1. Швидкий старт

Потрібні:

- **Node.js 20+** — збірка сторінок;
- **Python 3** — локальний сервер і генерація іконок;
- **Pillow** — для `scripts/brand.py`;
- **ffmpeg** — лише якщо перегенеровуватимете фото/відео.

```bash
npm run build      # зібрати HTML, sitemap, robots, manifest
npm run serve      # http://127.0.0.1:4173/
```

Або одним кроком: `npm run preview`.

Збірка пише готові файли **прямо в корінь проєкту**, а не в `dist/`. Саме корінь і є
деплой-папкою.

## 2. Що деплоїти

На хостинг (Netlify, Vercel, Cloudflare Pages, звичайний Apache/Nginx) завантажте:

```
index.html
404.html
polyanytsia/
bukovel/
shale/
privacy/
assets/css/
assets/fonts/
assets/img/        (без підпапки src/)
assets/js/
assets/video/
favicon.ico
favicon.svg
robots.txt
sitemap.xml
site.webmanifest
```

Не потрібні на проді: `src/`, `scripts/`, `package.json`, `README.md` та
`assets/img/src/` (оригінали фото для перегенерації).

Сайт працює і з кореня домену, і з підпапки (як зараз на GitHub Pages): шляхи до
`assets/` відносні, а внутрішні URL і canonical беруться з `BASE_URL`.

### Важливо перед запуском

1. У `src/data.mjs` замініть:

   ```js
   export const BASE_URL = "https://skytiger777.github.io/lisihory-site";
   ```

   на реальний домен **без слеша в кінці**.

2. Перевірте, що домен збігається в:
   - `canonical` і `hreflang` на всіх сторінках;
   - Open Graph / Twitter-картках;
   - JSON-LD (`@id`, `url`, `image`);
   - `sitemap.xml`, `robots.txt`, `site.webmanifest`.

   Усі ці файли генеруються з `BASE_URL`, тому достатньо змінити його і виконати `npm run build`.

3. Замініть фото та відео на оригінали власника (див. розділ 4).

4. Перевірте актуальність цін, телефону, посилань на соцмережі та Booking.

## 4. Фото та відео

**Усі фото — тимчасові.** Вони взяті з публічних оголошень маєтку, щоб показати
реальний вигляд і пропорції. Перед комерційним запуском замініть їх на оригінальні
файли власника (або отримайте письмовий дозвіл на використання).

Як замінити:

1. Покладіть оригінали у `assets/img/src/` з тими самими іменами, що в `scripts/images.mjs`
   (наприклад `26-ter-68359481c5c1b.jpg`).
2. Запустіть `npm run images` — скрипт зробить WebP-варіанти 640/960/1200/1600/1800 px
   (залежно від типу фото) і **сам оновить `src/images.json`** розмірами та вагою.
3. Перевірте, що `width`/`height` у `<img>` збігаються з новими пропорціями.
4. Для OG-картки: `npm run brand` (потрібен Pillow).

Фонове відео `assets/video/hero.mp4` (1600×900, ~1,4 МБ, без звуку) згенероване з фото.
Його можна замінити власним MP4 (H.264, без звуку, бажано до 2–3 МБ) і оновити постер
`assets/img/hero-poster-*.webp`. Відео підключається ліниво після завантаження сторінки;
для `prefers-reduced-motion` і повільних мереж показується тільки постер.

## 6. Форма бронювання

Форма **не має бекенду** і не зберігає персональні дані на сайті. Після натискання
«Сформувати заявку» `assets/js/main.js`:

1. перевіряє ім'я, телефон (мінімум 9 цифр) і дати;
2. збирає текст заявки українською;
3. показує панель із кнопками:
   - **Viber** — відкриває чат із номером маєтку;
   - **Email** — `mailto:` з готовою темою та текстом;
   - **Копіювати** — копіює текст у буфер обміну.

Це свідоме рішення для статичного хостингу. Якщо потрібні заявки на сервер, підключіть
Formspree / Netlify Forms / власний endpoint і додайте обробник у `main.js`.

## 7. SEO та локальна видимість

На сайті є:

- `LocalBusiness` / `LodgingBusiness` JSON-LD з NAP, координатами, `checkinTime`,
  `checkoutTime`, `priceRange`, `amenityFeature`, `containsPlace` для чотирьох осель;
- `FAQPage` на головній і geo-сторінках (унікальні `@id`);
- `BreadcrumbList` на підсторінках;
- `ReserveAction` для бронювання;
- geo-мета: `geo.region`, `geo.placename`, `geo.position`, `ICBM`;
- сторінки під локальні запити: Поляниця, Буковель, шале в Карпатах;
- узгоджені NAP-дані в шапці, футері, контактах і схемі;
- `sitemap.xml`, `robots.txt`, canonical, `hreflang="uk"` / `x-default`;
- OG/Twitter-картка 1200×630.

**Немає вигаданих відгуків та `aggregateRating`.** Рейтинг не доданий навмисно:
краще посилатися на реальні профілі Google/Booking, ніж ризикувати мануальним
покаранням. Відгуки гостей варто додати лише після появи реальних текстів.

Після запуску:

1. додайте сайт у Google Search Console і надішліть `sitemap.xml`;
2. оновіть Google Business Profile (посилання на сайт, фото, години, категорії);
3. перевірте NAP на Google, Booking, Instagram, Facebook — телефон і адреса мають
   збігатися з сайтом;
4. простежте індексацію geo-сторінок і запити «котеджі Поляниця», «шале Буковель»,
   «відпочинок у Поляниці».

## 8. Доступність і продуктивність

Перевірено в Lighthouse (мобільний профіль, локальний сервер):

| Сторінка | Performance | Accessibility | Best Practices | SEO |
| --- | --- | --- | --- | --- |
| Головна | 98 | 100 | 100 | 100 |
| Поляниця | 86 | 100 | 100 | 100 |
| Буковель | 86 | 100 | 100 | 100 |
| Шале | 89 | 100 | 100 | 100 |
| Політика | 86 | 100 | 100 | 100 |
| 404 | 100 | 100 | 100 | 63 (очікувано, `noindex`) |

Performance трохи коливається між прогонами (84–98).

Що вже зроблено: `prefers-reduced-motion`, фокус-стилі, ARIA для меню/галереї/форми,
контраст тексту, `loading="lazy"` для зображень нижче згортки, `fetchpriority="high"`
для hero-постера, preload шрифтів, відсутність горизонтального скролу на 390 px.

Performance 84–90 на локальному Python-сервері без стиснення. На проді з Brotli/gzip
і CDN показники будуть вищими. Якщо потрібно ще швидше: увімкніть кешування статики
на 1 рік і HTTP/2, а також віддавайте `assets/` через CDN.

## 9. Локальна перевірка

```bash
npm run build
npm run serve
```

Далі відкрийте `http://127.0.0.1:4173/`.

Корисні ручні перевірки:

- меню на мобільному (390 px) відкривається/закривається, Escape працює;
- галерея: стрілки, перетягування, lightbox, Escape;
- карта: клік по фасаду підвантажує Google Maps iframe;
- форма: порожні поля підсвічуються, валідна заявка відкриває панель із Viber/email/copy;
- координати копіюються кнопкою біля адреси;
- усі внутрішні посилання та зображення існують.

## 10. Відомі обмеження

- Зараз `BASE_URL` вказує на GitHub Pages (`skytiger777.github.io/lisihory-site`). Перед запуском на власному домені його треба замінити.
- Фотографії — тимчасові, з публічних оголошень; потрібні оригінали власника.
- Форма не надсилає заявки на сервер — тільки готує повідомлення.
- Немає реальних відгуків і рейтингу (свідомо).
- Ціни та доступність помешкань статичні; для онлайн-бронювання з календарем
  потрібна інтеграція з Booking/власною системою.
- `assets/img/src/` містить оригінали для перегенерації; не деплойте їх.
